# حصّة — منصة المدرس

تطبيق عربي (RTL) لإدارة الطلاب والحصص، حضوري وأونلاين.

## المميزات
- لوحة المدرس: الطلاب، الفصول، الجدول، الاشتراكات، الاختبارات، المكتبة، التقارير
- ملف مستقل لكل طالب (مدفوعات، حضور، درجات، واجبات، ملفات، ملاحظات)
- بوابة ولي الأمر
- غرفة الحصة: فيديو، ميكروفون، مشاركة الشاشة، PDF، سبورة متزامنة، شات، رفع يد
- وضع ليلي، متوافق مع الموبايل والتابلت والكمبيوتر

## التشغيل
افتح `index.html` في المتصفح، أو فعّل GitHub Pages من Settings ← Pages.

## ملاحظات
- البيانات الحالية تجريبية وتُحفظ في الذاكرة فقط.
- التزامن يعمل بين تبويبات المتصفح على جهاز واحد؛ للتزامن عن بُعد يلزم خادم (WebSocket / WebRTC).
- البنية متعددة المدرسين (`DB.t[tenantId]`) لتسهيل التوسع لاحقًا.
