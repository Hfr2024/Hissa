# WORM AI VIDEO STUDIO — النسخة المجانية للموبايل

## مهم قبل الاستخدام
هذه نسخة مجانية بدون API مدفوع. لا يمكن ضمان توليد فيديو AI بلا حدود مباشرة على هاتف أندرويد فقط؛ نماذج توليد الفيديو ثقيلة عادةً وتحتاج خوادم أو جهازًا قويًا. لذلك هذه النسخة عبارة عن تطبيق ويب قابل للتثبيت على الهاتف يساعدك على كتابة وصف احترافي، حفظه/نسخه، ثم فتح خدمات توليد فيديو عبر المتصفح التي قد توفر رصيدًا مجانيًا أو استخدامًا محدودًا.

- لا يوجد API key ولا اشتراك مدفوع مدمج.
- لا يوجد توليد فيديو محلي داخل التطبيق.
- توافر الخطة المجانية في المواقع الخارجية يتغير وقد يتطلب حسابًا.
- لا تدخل كلمات مرورك أو مفاتيح API في هذا التطبيق.

## تشغيله على أندرويد
1. فك ضغط الملف.
2. ارفع محتويات المجلد إلى مستودع GitHub جديد.
3. من GitHub افتح Settings → Pages، اختر Deploy from a branch، ثم `main` و`/ (root)`.
4. افتح رابط GitHub Pages من Chrome على الهاتف.
5. من قائمة Chrome اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».

يمكن تشغيل `index.html` مباشرة في المتصفح أيضًا، لكن بعض الميزات مثل التثبيت تكون أفضل عبر HTTPS.

## الخدمات
تفتح الأزرار صفحات البحث/الخدمات في المتصفح فقط؛ لا نضمن أن كل خدمة توفر توليد فيديو مجانيًا في كل وقت. راجع شروطها قبل الاستخدام.
